# S7-1200 & S7-1500 Configuration Manual for Web-HMI

## 1. Обязательные требования к конфигурации в TIA Portal

Для обеспечения возможности чтения и записи данных контроллеров S7-1200 и S7-1500 через классический протокол S7 Communication необходимо выполнить три ключевых шага в TIA Portal (версии V13, V14, V15, V16, V17, V18, V19):

---

## 2. Шаг 1: Активация доступа PUT/GET в свойствах CPU

Начиная с версий прошивок Firmware >= 4.0 (для S7-1200) и Firmware >= 1.5 (для S7-1500), доступ по протоколу PUT/GET отключен по умолчанию из соображений безопасности.

### Инструкция:
1. В дереве проекта TIA Portal выберите контроллер и откройте **Device configuration**.
2. Выделите CPU и в нижней панели откройте вкладку **Properties -> General**.
3. Перейдите в раздел **Protection & Security** -> **Connection mechanisms**.
4. Установите флаг напротив пункта:
   **"Permit access with PUT/GET communication from remote partner"** (Разрешить доступ с помощью PUT/GET связи со стороны удаленного партнера).

![PUT/GET Setting](docs/siemens/s7-1500/82212115_s7_communication_s7-1500_en.pdf)

---

## 3. Шаг 2: Отключение Optimized Block Access для блоков данных (DB)

По умолчанию в TIA Portal все новые блоки данных создаются в оптимизированном формате (**Optimized block access**). При таком формате байтовые смещения скрыты, а порядок переменных в памяти определяется компилятором. Для классического S7Comm блокам данных HMI необходимо задать стандартный формат.

### Инструкция:
1. В дереве проекта найдите целевой блок данных (например, `DB100_HMI`).
2. Нажмите правой кнопкой мыши и выберите **Properties** (Свойства).
3. Перейдите на вкладку **Attributes** (Атрибуты).
4. **Снимите флаг** с пункта **"Optimized block access"** (Оптимизированный доступ к блоку).
5. Нажмите **OK** и подтвердите диалоговое окно перекомпиляции блока.
6. В таблице переменных блока данных появится колонка **Offset** (Смещение: `0.0`, `2.0`, `4.0` и т.д.).

---

## 4. Шаг 3: Настройка уровней доступа (Protection Level)

1. В свойствах CPU перейдите в раздел **Protection & Security -> Access level**.
2. Убедитесь, что выбран один из следующих уровней:
   - **Full access incl. fail-safe (no protection):** полный доступ.
   - **Read access:** доступ только для чтения (при этом запись уставок с HMI будет блокироваться CPU).
   - **HMI access:** разрешен доступ HMI-панелей и SCADA-систем.
3. Если задан пароль доступа, в классическом S7Comm аутентификация паролем не поддерживается напрямую, поэтому для портов HMI требуется режим "HMI access" без ограничения по паролю на чтение/запись non-optimized DB.

## 5. Параметры сетевого подключения для SCADA

| Параметр | S7-1200 | S7-1500 |
| :--- | :--- | :--- |
| **Порт** | `102` (TCP) | `102` (TCP) |
| **Rack (Стойка)** | `0` | `0` |
| **Slot (Слот)** | **`1`** | **`1`** |
| **TSAP (HMI Client)** | `0x0301` / `0x0200` | `0x0301` / `0x0200` |
| **TSAP (PLC Server)** | `0x0300` / `0x0301` | `0x0300` / `0x0301` |
| **Максимальный размер PDU** | `240 байт` | `960 байт` |

---

## 6. Загрузка изменений в контроллер (Download to PLC)

1. Нажмите кнопку **Compile** (Скомпилировать) для всего проекта (Software rebuild all).
2. Выполните **Download to device** (Загрузка в устройство).
3. При запросе TIA Portal переведите CPU в режим **STOP** (если изменились свойства аппаратной конфигурации и структура DB), выполните загрузку и верните CPU в режим **RUN**.
