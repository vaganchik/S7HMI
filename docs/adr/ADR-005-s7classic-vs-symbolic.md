# ADR-005: Эволюция драйверов: S7 Classic vs Symbolic / OPC UA

## Статус
Принято (Accepted)

## Контекст
S7 Classic обеспечивает универсальную работу с S7-300, S7-1200 и S7-1500, но требует Non-Optimized DB и абсолютных адресов. Современные проекты на S7-1500 часто используют Optimized DB и символьные имена.

## Решение
Разработать сервер на базе расширяемого интерфейса `IPlcDriver`:
- Версия 1 (MVP): `S7ClassicDriver` (абсолютная адресация, универсальная совместимость).
- Версия 2 (Evolution): `OpcUaDriver` (символьная адресация, Optimized DB, встроенный сервер безопасности OPC UA).
- Переключение драйвера на уровне конфигурации конкретного PLC без изменения кода HMI и теговой модели.

## Последствия
- Быстрый запуск MVP с поддержкой всего парка оборудования (включая старые S7-300).
- Бесшовная миграция на современные стандарты OPC UA в будущем.
