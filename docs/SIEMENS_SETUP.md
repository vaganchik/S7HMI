# Руководство по настройке ПЛК Siemens S7-1200 / S7-1500 в TIA Portal

Данное руководство содержит обязательные шаги по конфигурированию проекта в Siemens TIA Portal (v16, v17, v18, v19) для обеспечения прямого и быстрого обмена по протоколу S7comm.

---

## 1. Разрешение доступа по протоколу PUT/GET

По умолчанию в контроллерах Siemens S7-1200 (прошивка v4.0+) и S7-1500 доступ по протоколу S7comm заблокирован встроенной системой безопасности CPU.

### Инструкция:
1. В дереве проекта TIA Portal откройте свойства контроллера: **Device configuration &rarr; CPU Properties**.
2. В левом меню свойств перейдите в раздел: **Protection & Security &rarr; Connection mechanisms**.
3. Установите флаг (галочку):
   ```text
   [x] Permit access with PUT/GET communication from remote partner
   ```
4. Выполните компиляцию аппаратной конфигурации: **Right click CPU &rarr; Compile &rarr; Hardware (rebuild all)**.
5. Загрузите конфигурацию в контроллер: **Download to device &rarr; Hardware configuration**.

---

## 2. Настройка блоков данных (DB) — Отключение оптимизированного доступа

Для того чтобы переменные в DB имели фиксированные абсолютные смещения байтов (`DBX`, `DBW`, `DBD`, `DBB`), необходимо отключить режим "Optimized block access".

### Инструкция:
1. В дереве проекта найдите нужный блок данных (например, `DB10 "HMI_Data"`, `DB20 "Alarms"`).
2. Нажмите правой кнопкой мыши по блоку &rarr; **Properties**.
3. Перейдите во вкладку **Attributes**.
4. **Снимите флаг (галочку)**:
   ```text
   [ ] Optimized block access
   ```
5. Нажмите **OK** и согласитесь с предупреждением о пересчете смещений.
6. В таблице переменных блока появится колонка **Offset** (0.0, 2.0, 4.0 и т.д.).
7. Скомпилируйте и загрузите блок данных в ПЛК.

---

## 3. Рекомендуемая структура блоков данных (DB) для HMI

Для максимальной производительности опроса (сжатие в 1 сетевой PDU пакет) рекомендуется группировать данные по смежным адресам:

### Пример структуры `DB10 "Line_HMI"`:

```pascal
TYPE "type_MotorTelemetry"
STRUCT
    ActualSpeed_Hz   : Real;    // DBD0   - Фактическая частота (Гц)
    Current_A        : Real;    // DBD4   - Ток двигателя (А)
    Status_Running   : Bool;    // DBX8.0 - Флаг работы
    Status_Fault     : Bool;    // DBX8.1 - Флаг аварии ЧРП
    Mode_Auto        : Bool;    // DBX8.2 - Режим Авто
    SpeedSetpoint_Hz : Real;    // DBD10  - Уставка частоты
END_STRUCT
END_TYPE
```

---

## 4. Экспорт тегов и аварий через TIA Openness XML

Система S7 HMI поддерживает прямой парсинг файлов экспорта TIA Portal Openness (`.xml`).

1. В TIA Portal выберите блок данных или таблицу тегов (PLC Tags).
2. Выполните экспорт в XML: **Export as XML...**
3. В Web-HMI перейдите во вкладку **«📄 TIA XML»**.
4. Загрузите файл XML — теги, адреса, типы данных (`Real`, `DInt`, `Bool`) и комментарии автоматически импортируются в SCADA-систему без ручного ввода!
