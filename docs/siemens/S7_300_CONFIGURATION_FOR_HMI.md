# S7-300 Hardware & Network Configuration Manual for HMI

## 1. Обзор архитектуры подключения

Контроллеры SIMATIC S7-300 поддерживают два основных варианта Ethernet-подключения:
1. **CPU со встроенным интерфейсом PROFINET (PN):** CPU 315-2 PN/DP, CPU 317-2 PN/DP, CPU 319-3 PN/DP.
2. **CPU с коммуникационным процессором CP 343-1:** CPU 312, 313C, 314, 315-2 DP + CP 343-1 Lean / Standard / Advanced.

---

## 2. Настройка в SIMATIC Manager (STEP 7 V5.x) или TIA Portal

### 2.1 Конфигурация аппаратной части (HW Config)
1. Откройте **HW Config** проекта.
2. Для CPU со встроенным Ethernet:
   - Дважды щелкните по интерфейсу **PN-IO** на CPU.
   - В свойствах интерфейса перейдите в раздел **General -> Properties**.
   - Задайте статический IP-адрес (например, `192.168.1.10`) и маску подсети (`255.255.255.0`).
   - Убедитесь, что интерфейс подключен к подсети Industrial Ethernet.
3. Для коммуникационного процессора **CP 343-1**:
   - Установите модуль CP 343-1 в свободный слот корзины (обычно **Slot 4** или выше).
   - В свойствах CP 343-1 задайте IP-адрес и подключите к сети Industrial Ethernet.

---

## 3. Адресация Rack / Slot и TSAP в SCADA

| Параметр | CPU со встроенным PN | CPU с коммуникационным процессором CP 343-1 |
| :--- | :--- | :--- |
| **IP-адрес** | IP-адрес интерфейса CPU | IP-адрес интерфейса CP 343-1 |
| **Rack (Стойка)** | `0` | `0` |
| **Slot (Слот)** | **`2`** (Слот CPU) | **`2`** (Слот CPU) или **`4+`** (Слот CP343) |
| **Connection Type**| OP/HMI (`0x02`) или PG (`0x01`)| OP/HMI (`0x02`)|
| **Remote TSAP** | `0x0202` (или `0x0102`) | `0x0202` (или `0x0302`) |
| **Local TSAP** | `0x0100` (или `0x0200`) | `0x0100` |

---

## 4. Требования к блокам данных (Data Blocks)

- В S7-300 все блоки данных по умолчанию являются стандартными (non-optimized) и имеют фиксированные байтовые смещения.
- Никаких дополнительных настроек защиты или активации PUT/GET в S7-300 производить не требуется (функция сервера S7 Communication активна всегда на уровне прошивки).
- Убедитесь, что созданные DB загружены в память контроллера (**Download to Module**).
