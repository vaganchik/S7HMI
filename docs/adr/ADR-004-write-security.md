# ADR-004: Безопасность и конвейер верификации операций записи

## Статус
Принято (Accepted)

## Контекст
Случайная или несанкционированная запись в память контроллера технологического процесса несет прямую угрозу безопасности персонала и оборудования.

## Решение
Реализовать многоуровневый конвейер защиты `WriteManager`:
1. Глобальный предохранитель `WRITE_ENABLED=false` по умолчанию.
2. Режим эмуляции `DRY_RUN_MODE`.
3. Обязательный флаг `allowWrite: true` на уровне каждого тега.
4. Валидация типов данных и допустимых диапазонов (`min` / `max`).
5. Неизменяемый структурированный журнал аудита всех попыток записи.

## Последствия
- Исключение случайной записи физических выходов и невалидных значений.
- Полная прозрачность и аудит действий операторов.
